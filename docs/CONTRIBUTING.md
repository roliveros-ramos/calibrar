# Contributing to calibrar

Thank you for your interest in contributing to **calibrar**.

Contributions are welcome, including bug reports, questions,
documentation improvements, examples, feature suggestions, and code
contributions.

## Reporting bugs

If you find a bug, please please [open an
issue](https://github.com/roliveros-ramos/calibrar/issues).

When possible, please include:

- a clear description of the problem;
- a minimal reproducible example;
- the version of `calibrar` you are using;
- your R version and operating system;
- any relevant error messages or warnings.

## Suggesting improvements

Suggestions for improving the package, documentation, examples, or
vignettes are welcome.

Please open an issue describing:

- the motivation for the improvement;
- the expected behaviour or output;
- any relevant examples or use cases.

## Contributing code

Code contributions can be made through pull requests.

Before submitting a pull request, please:

- open an issue first if the change is substantial;
- keep the proposed change focused;
- follow the existing coding style of the package;
- add or update documentation when relevant;
- add or update examples or tests when appropriate;
- check that the package can be built and checked successfully.

For R code, please use clear object names and keep functions as simple
and focused as possible. Existing package conventions should be followed
where possible.

## Documentation

Documentation improvements are especially welcome. This includes
corrections, clarifications, examples, vignettes, and improvements to
function documentation.

For exported functions, documentation should be written using `roxygen2`
comments and should describe the purpose of the function, its arguments,
return value, and relevant details.

## Pull requests

When submitting a pull request, please include a short description of:

- what the pull request changes;
- why the change is useful;
- whether it affects existing behaviour;
- whether documentation or tests were updated.

## Questions

Questions about using `calibrar`, interpreting outputs, or understanding
the documentation can also be submitted as issues.

## Code of conduct

Please keep discussions constructive, respectful, and focused on
improving the package.

The calibrar package is released with a [Contributor Code of
Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By contributing to this project, you agree to abide by its terms.
